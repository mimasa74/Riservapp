Operazioni tipiche in React

// Caricare cervo (real-time)
onSnapshot(doc(db, "species", "cervo"), snap => setData(snap.data()))

// Rettore tocca un quadratino
updateDoc(doc(db, "species", "cervo"), {
  categories: newCategories,   // array aggiornato
  updatedAt: serverTimestamp()
})

// Reset stagione
updateDoc(doc(db, "species", "cervo"), {
  categories: categories.map(c => ({...c, abbattuti: 0, stato: "aperto"})),
  updatedAt: serverTimestamp()
})

Totale documenti in Firestore: 3 (specie) + N post bacheca + M turni ruote.
Letture per caricare l'app: 3 onSnapshot permanenti (uno per specie) + query bacheca.
Costo mensile stimato: praticamente zero — Firestore free tier è 50.000 letture/giorno.
