Firestore — struttura finale

firestore/
├── species/cervo      { anno, note, alert, updatedAt, categories:[...] }
├── species/capriolo   { anno, note, alert, updatedAt, categories:[...] }
├── species/camoscio   { anno, penalita, note, alert, updatedAt, zone:{campa,tovel} }
├── bacheca/{id}       { tipo, testo, foto_url, pdf_url, data, notifica }
├── ruote/{specieId}   { immagine_url, updatedAt }
├── users_locations/{deviceId}  { nome, latitude, longitude, timestamp }
└── geofences/riserva-tuenno    { vertices:[...32 punti...] }

Ruota — semplificata

Specie Contenuto Frequenza aggiornamento
Cervo 1 foto (ruota palcuti) ~1 volta a settimana
Camoscio 1 foto (ruota) ~ogni 2 mesi
Capriolo 1 foto (se serve) raramente / bacheca

Primo avvio — cacciatore

1. Schermata benvenuto → inserisci nome
2. Richiesta permesso notifiche
3. Richiesta permesso GPS ("sempre" su Android)
4. Entra nell'app → nome salvato in localStorage + deviceId generato

Geolocalizzazione (Fase 6)

• Telefono manda posizione ogni 5 minuti (notifica persistente Android)
• Cloud Function controlla se dentro poligono 32 vertici
• Se dentro → appare su mappa Rettore con nome
• Se fuori → scompare
• iOS: non supportato (pochi utenti)
• Privacy: solo Rettore vede la mappa
