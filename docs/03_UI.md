# Interfaccia utente — nessuna logica, nessun database

---

## Navigazione principale

Swipe orizzontale tra 4 schermate:
```
Bacheca → Capriolo → Cervo → Camoscio
   1          2         3        4
```

Indicatori posizione: pallini in cima — ● ○ ○ ○
Nessuna bottom nav bar — più spazio per i contenuti.

## Blocco categoria — layout verticale

Ogni categoria è un blocco separato con bordo:

```
┌─────────────────────────────────┐
│ NOME CATEGORIA                  │  ← testo grande, bold, uppercase
│ (descrizione)                   │  ← testo medio, grigio
│                                 │
│ n. X   □ □ □ □ □ □             │  ← quadratini sotto
└─────────────────────────────────┘
```

**Specifiche testo:**
- Nome: font grande, bold, uppercase, leggibile per anziani
- Descrizione: font medio, grigio, sotto il nome
- Spazio generoso tra nome e quadratini

**Specifiche quadratini:**
- Dimensione: grandi, facili da toccare
- Gap: equidistanti
- Wrap: automatico su 2 righe se non ci stanno
- Vuoto: bordo verde #5C6B3A, sfondo trasparente
- Pieno: sfondo rosso #8B1A1A, X nera al centro

**Stato CHIUSO:**
```
┌─────────────────────────────────┐
│ NOME CATEGORIA           CHIUSO │
└─────────────────────────────────┘
```
- Nessun quadratino visibile al cacciatore
- Card più bassa (solo nome + badge)

## Blocco categoria — differenze per ruolo

| Stato | Cacciatore | Rettore |
|-------|-----------|---------|
| aperto | nome + desc + n.X + □□□ (visivo) | nome + desc + n.X + □□□ (tappabili) |
| chiuso | nome + CHIUSO (no quadratini) | nome + n.X + ☒☒☒ + CHIUSO (tappabili) |

## Pagina Ruote e Squadre

Aperta da pulsante in fondo alla schermata assegnazioni.
Navigazione: freccia indietro in cima.

```
← indietro    RUOTE E SQUADRE — CERVO

┌─────────────────────────────────┐
│ Mario Rossi          12/09      │
├─────────────────────────────────┤
│ Luigi Bianchi        14/09      │
├─────────────────────────────────┤
│ ...                             │

```

## Vista Rettore — differenze visive

```
- Dot verde sul logo (segnale silenzioso modalità admin)
- Quadratini tappabili
- Pulsante + nella pagina Ruote per aggiungere turni
- Cestino su ogni turno per eliminare
- Pulsante + nella bacheca per creare post
- Cestino su ogni post per eliminare
- Pulsante impostazioni nell'header
```
