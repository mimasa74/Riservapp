# Etichette di triage

Le skill parlano di cinque ruoli. Qui vivono come valori della riga `Status:` nei
file sotto `.scratch/` (vedi `issue-tracker.md`): non ci sono etichette vere,
perché non c'è un tracker esterno.

| Ruolo nelle skill | Valore in questo repo | Significato                                  |
| ----------------- | --------------------- | -------------------------------------------- |
| `needs-triage`    | `needs-triage`        | Da valutare, non ancora deciso se si fa       |
| `needs-info`      | `needs-info`          | Manca una risposta di Michele per andare avanti |
| `ready-for-agent` | `ready-for-agent`     | Scritto abbastanza bene da farlo senza chiedere |
| `ready-for-human` | `ready-for-human`     | Tocca a Michele: va guardato, deciso o provato |
| `wontfix`         | `wontfix`             | Non si fa                                     |

`ready-for-human` è quello che si usa più spesso qui: Michele valuta guardando, e
molte decisioni di design non si chiudono senza che veda l'anteprima.
